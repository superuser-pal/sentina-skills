# In Progress

Beta skills kept for testing and feedback. They are excluded from the default plugin and top-level README until stable.

- **[loop-me](./loop-me/SKILL.md)**: Grill yourself into implementable workflow specs over multiple sessions, using the current directory as a stateful workspace.
- **[chief-of-staff](./chief-of-staff/SKILL.md)**: Pursue a long-running goal while coordinating delegated tactical work and protecting the strategic context.
- **[writing-beats](./writing-beats/SKILL.md)**: Shape a document or article as a journey of beats, choose-your-own-adventure style.
- **[writing-fragments](./writing-fragments/SKILL.md)**: Grilling session that mines fragments and appends them as raw material.
- **[writing-shape](./writing-shape/SKILL.md)**: Take raw material and shape it into structured prose paragraph by paragraph.
