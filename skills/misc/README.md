# Misc

Miscellaneous tools kept around but not promoted in the main plugin.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**: Set up Claude Code hooks to block dangerous git commands (push, reset --hard, clean, etc.) before they execute.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**: Set up pre-commit hooks with lint-staged, Prettier, type checking, and tests.
- **[visual-explainer](./visual-explainer/SKILL.md)**: Generate self-contained HTML diagrams, dashboards, and slide decks (Sentina-branded theme included).
- **[diagram-design](./diagram-design/SKILL.md)**: Create 39 types of branded editorial diagrams as standalone HTML/SVG/PNG (Sentina style guide included).
- **[excalidraw](./excalidraw/SKILL.md)**: Create and refine diagrams on a live Excalidraw canvas via the mcp_excalidraw MCP server/CLI.
