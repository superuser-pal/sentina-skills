# Misc

Miscellaneous tools kept around but not promoted in the main plugin.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**: Set up Claude Code hooks to block dangerous git commands (push, reset --hard, clean, etc.) before they execute.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**: Set up pre-commit hooks with lint-staged, Prettier, type checking, and tests.
- **[visual-explainer](./visual-explainer/SKILL.md)**: Generate self-contained HTML diagrams, dashboards, and slide decks (Sentina-branded theme included).
- **[diagram-design](./diagram-design/SKILL.md)**: Create 39 types of branded editorial diagrams as standalone HTML/SVG/PNG (Sentina style guide included).
- **[excalidraw](./excalidraw/SKILL.md)**: User-invoked. Generate an editable `.excalidraw` diagram file from a natural-language description, no live canvas or MCP server required.
- **[skill-architect](./skill-architect/SKILL.md)**: User-invoked. Guided-discovery conversation for building a new skill from scratch (discovery, architecture, craft, validate, deliver).
- **[subagent-creator](./subagent-creator/SKILL.md)**: User-invoked. Guide for creating agent-agnostic subagent/persona definitions with isolated context.
- **[the-fool](./the-fool/SKILL.md)**: User-invoked. Plays devil's advocate against a plan or decision via Socratic, pre-mortem, red-team, dialectic, or evidence-audit critique.
- **[the-jury](./the-jury/SKILL.md)**: User-invoked. Convenes a 3-5 subagent panel that deliberates blind-then-anonymous and returns one committed verdict.
- **[playwright-skill](./playwright-skill/SKILL.md)**: User-invoked. General-purpose browser automation with Playwright; requires `npm run setup` before first use.
